# OneEye 無限畫布作品集

把所有作品放在一張無限大的畫布上，觀看者只需要拖曳平移、滾輪縮放就能瀏覽。
純前端、不需要安裝任何東西，直接用瀏覽器開啟 `index.html` 即可。

## 兩種模式

| 模式 | 開啟方式 | 能做什麼 |
| --- | --- | --- |
| 觀看者 | 開啟 `index.html` | 拖曳平移、滾輪／捏合縮放、雙擊作品聚焦、點影片播放 |
| 管理者（編輯） | 開啟 `edit.html`（或 `index.html?edit`） | PureRef 式編輯、匯入、儲存 |

> 編輯模式需要 **Chrome 或 Edge**（使用瀏覽器的檔案系統存取功能把檔案寫回資料夾）。

## 用 VS Code Live Server 開啟時

Live Server 只要偵測到資料夾內檔案變動就會自動重新整理頁面，匯入時寫入圖片會讓頁面一直重載、匯入中斷。
本資料夾已附 `.vscode/settings.json` 讓 Live Server 忽略 `assets/` 與 `data/`（設定後請重新啟動 Live Server）。
也可以不用 Live Server，直接用 Chrome 開啟 `edit.html`。

## 第一次編輯

1. 用 Chrome / Edge 開啟 `edit.html`
2. 按上方的「連接資料夾」，選擇這個 OneEye 資料夾（有 `index.html` 的那一層），允許「編輯」權限
3. 從檔案總管把圖片／影片（可多選，或直接拖整個資料夾）拖進畫布
4. 匯入時會自動：
   - 把原始檔複製到 `assets/original/`（影片在 `assets/video/`）
   - 產生 64 / 256 / 1024 / 2048px 的縮圖到 `assets/lod/`
5. 編輯後會自動儲存到 `data/canvas-data.js`（也可按 Ctrl+S）

瀏覽器會記住連接過的資料夾，下次開啟只需要再按一次「連接資料夾」允許權限。

## 編輯操作

| 操作 | 功能 |
| --- | --- |
| 點選 / Shift+點選 | 選取 / 加選、取消 |
| 空白處拖曳 | 框選 |
| 拖曳角落方塊 | 等比縮放（按住 Alt 以中心縮放） |
| 拖曳上方圓點 | 旋轉（按住 Shift 每 15° 吸附） |
| 中鍵 / 右鍵 / 空白鍵+拖曳 | 平移畫面 |
| 滾輪 | 縮放（觸控板：雙指平移、捏合縮放） |
| 底部「對齊 ▾」 | 靠左／右／上／下對齊；對齊後會沿另一方向自動推開，不會重疊 |
| 底部 ↔ ↕ 欄位 | 顯示選取作品的橫向／直向間距；不一致時顯示 ?，輸入數值即可統一間距 |
| 底部其他按鈕 | 自動排列、等高、複製、置頂/置底、旋轉歸零、輸出框線、刪除 |
| T 或「T 文字」 | 在畫布上點一下輸入文字（Enter 換行，Ctrl+Enter 或點別處完成）；雙擊或按 Enter 重新編輯；選取後底部「T 顏色」改顏色，拖角落改大小 |
| R 或「▭ 框線」 | 拖曳拉出框線；先選取作品再按，會直接建立包住它們的框線 |
| 框線 | 點邊框或名稱選取（可 Shift 多選），拖角落自由調整大小（Shift 等比），雙擊改名，Ctrl+D 複製 |
| 輸出框線 | 選取一或多個框線 →「輸出框線」，可選背景顏色或透明 PNG、倍率 1x–4x（用原圖解析度輸出） |
| Ctrl+D / Ctrl+C / Ctrl+V | 複製 / 拷貝 / 貼上（貼在滑鼠位置） |
| 方向鍵（+Shift） | 微調位置 |
| Ctrl+方向鍵 | 選取的作品往該方向對齊（不重疊） |
| Ctrl+A / Delete / Esc | 全選 / 刪除 / 取消選取 |
| Ctrl+Z / Ctrl+Shift+Z | 復原 / 重做 |
| Ctrl+S | 儲存 |
| 0 / F | 顯示全部 / 聚焦到選取 |
| 雙擊影片 | 播放 / 暫停 |
| 「預覽」按鈕 | 切換成觀看者畫面確認效果 |

## 效能設計

- **視野裁切**：用空間格點索引，只處理與畫面相交的作品，畫面外的完全不畫也不載入。
- **LOD 降階**：依作品在螢幕上的實際像素挑選最接近的縮圖層級，拉遠時只解碼 64px／256px 小圖。
- **色塊模式**：作品小到幾個像素時改畫平均色色塊；畫面內作品越多，切換門檻越高（5000 張同時在畫面內約 3ms 一幀）。
- **漸進載入**：高解析版本還沒載入時先顯示已有的低解析版本，從畫面中心開始優先載入。
- **記憶體上限**：解碼後的圖片放在 LRU 快取，超過約 512MB 會釋放最久沒看到的。
- **影片**：平常只畫封面縮圖，播放時才建立影片元素；離開畫面自動暫停。

## 上線

整個資料夾就是靜態網站，可以直接上傳到 GitHub Pages、Netlify、Cloudflare Pages 或任何主機。
訪客開 `index.html` 就是觀看模式。網站上沒有後端，就算有人打開 `?edit` 也無法改到伺服器上的檔案；
編輯一律在你自己電腦上的資料夾進行，改完再重新上傳。

## 資料夾結構

```
index.html          主頁（觀看者）
edit.html           進入編輯模式的捷徑
css/style.css
js/                 util / store / renderer / video / importer / editor / main
data/canvas-data.js 畫布資料（自動產生）
assets/original/    原始圖片
assets/video/       原始影片
assets/lod/         自動產生的縮圖金字塔
```

框線只在編輯模式顯示，觀看者看不到。

刪除畫布上的作品不會刪掉 `assets/` 裡的檔案（避免誤刪），需要時可手動清理。
