編輯模式操作

拖曳檔案到畫布匯入圖片／影片（可一次多個）
點選 / Shift+點選選取 / 加選、取消
在空白處拖曳框選
拖曳角落控制點等比縮放（Alt：以中心縮放）
拖曳上方圓點旋轉（Shift：每 15° 吸附）
中鍵／右鍵／空白鍵+拖曳平移畫面
滾輪縮放（觸控板雙指為平移，捏合為縮放）
方向鍵（Shift 加大）微調位置
Ctrl+方向鍵往該方向對齊（不重疊）
Ctrl+A / Delete全選 / 刪除
Ctrl+Z / Ctrl+Shift+Z復原 / 重做
Ctrl+S儲存（另有自動儲存）
T 或「T 文字」在畫布上點一下輸入文字；Ctrl+Enter 或點別處完成
雙擊文字 / Enter重新編輯文字；底部「T 顏色」改顏色，拖角落改大小
R 或「框線」拖曳拉出框線；有選取作品時直接包住選取範圍
拖曳框線角落自由調整框線大小（Shift 維持比例）
點框線邊緣 / 名稱選取框線（雙擊可改名）
Ctrl+D / Ctrl+C / Ctrl+V複製 / 拷貝 / 貼上（貼在滑鼠位置）
↔ ↕ 欄位顯示目前間距，? 表示不一致；輸入數值套用
0 / F顯示全部 / 聚焦選取
雙擊影片播放 / 暫停
放開以匯入到畫布
